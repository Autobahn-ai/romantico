## 1. Learning philosophy

### Principles

1. **Learn by building** — every week produces a tangible artifact  
2. **Sell early** — learning stops being theoretical when a real client is waiting  
3. **One tool at a time** — master n8n before touching alternatives  
4. **Niche knowledge = sales advantage** — Handwerk vocabulary matters as much as n8n  
5. **Templates over talent** — reusable docs beat improvising  
6. **80/20 technical** — 20% of n8n features solve 80% of client problems  

### What you are NOT learning

- Python, JavaScript, SQL (beyond basics)  
- Custom app development  
- ERP implementation certification  
- Enterprise data architecture  
- Advanced statistics / data science  

### Learning split by phase

| Phase | Technical % | Niche % | Business % |
|-------|-------------|---------|------------|
| 1 (Foundation) | 60% | 25% | 15% |
| 2 (Side hustle) | 40% | 20% | 40% |
| 3 (Quit prep) | 20% | 15% | 65% |
| 4 (Full-time) | 30% | 15% | 55% |

## 8. Tool curricula (deep dives)

### n8n — full curriculum

**Level 1 (weeks 1–4):** Basics  
- [ ] Interface, workflows, executions, credentials  
- [ ] Nodes: Manual Trigger, Schedule, Set, IF, Switch, Merge  
- [ ] Google Sheets: Read, Append, Update  
- [ ] Email: Send via SMTP/Gmail  
- [ ] HTTP Request basics  
- [ ] Webhook trigger  

**Level 2 (weeks 5–12):** Client-ready  
- [ ] Error Trigger workflow (global error handler)  
- [ ] Sub-workflows  
- [ ] Expression syntax `{{ }}` confidently  
- [ ] Code node (copy-paste JSON parsing only)  
- [ ] Wait node, scheduling logic  
- [ ] Credential management per client  
- [ ] Workflow export/import (backup)  

**Level 3 (months 6–12):** Professional  
- [ ] Queue mode awareness  
- [ ] Environment variables  
- [ ] Multiple environments (dev/prod)  
- [ ] Webhook security (basic auth)  
- [ ] Rate limiting patterns  
- [ ] Monitoring: failed execution alerts  

**Level 4 (year 2):** Scale  
- [ ] Subcontractor handoff documentation  
- [ ] Client-specific instance vs shared instance decision  
- [ ] Performance optimization for 1000+ row sheets  

---

### Google Sheets — full curriculum

**Level 1:**  
- [ ] Data validation, conditional formatting  
- [ ] FILTER, SORT, UNIQUE  
- [ ] QUERY function  
- [ ] IMPORTRANGE  
- [ ] Protected ranges and sheets  

**Level 2:**  
- [ ] ARRAYFORMULA  
- [ ] Named ranges  
- [ ] INDIRECT for dynamic references  
- [ ] Import from CSV/form  
- [ ] Sharing permissions model  

**Level 3:**  
- [ ] Sheet as database (do's and don'ts)  
- [ ] Performance with 5000+ rows  
- [ ] Backup/versioning discipline
